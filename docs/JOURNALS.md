# 期刊范围与纳入标准

“大子刊”是中文科研交流中的习惯说法，没有统一的官方分级。本报告以用户举例的 Nature Communications 为锚点，建立六本核心期刊名单，另列四本交叉或扩展刊；这不是影响因子、JCR或中科院分区排名。Nature、Science、Cell主刊不混入子刊统计；Scientific Reports及IEEE电力期刊也不计入核心名单。

检索日期：2026年11月2日（Asia/Shanghai）。近三年按2024、2025、2026三个日历年处理，截止2026-11-02；不等于向前滚动36个月，也不覆盖尚未结束的2026全年。优先采用首次在线发表年份，个别Joule记录仅能核验卷期日/月，已逐条注明。

## 电网边界

- 纳入：输配电、潮流、规划、控制、稳定性、停电恢复、预测、电力市场、系统级储能、需求响应、车网互动及电力气候风险。
- 标记后保留：以电网作验证案例的通用方法、与电网决策相关的电源转型和部门耦合研究。
- 背景补充：不建模网络运行但涉及光伏资源、城市能耗、AI用电或电力资产的研究，不用于严格电网交叉命中。
- 不纳入：仅电池材料/器件效率、与电力无关的计算网格/神经网格细胞、新闻重复解读、时间窗外论文。
